##Sliding Puzzle

A responsive sliding tile puzzle game built with HTML, CSS, and JavaScript.

Three difficulty levels: 3×3, 4×4, and 5×5
Five color themes
Move counter, timer, and personal best scores
Keyboard, mouse, and touch controls
Animations and win celebrations
PWA support with offline play
Run Locally

Open index.html in a browser. For full PWA functionality, serve the project over HTTPS or localhost.
